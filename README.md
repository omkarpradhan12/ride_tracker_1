# Swift Ride 🏍️

Swift Ride is a feature-rich motorcycle ride tracker built with Flutter. It provides real-time GPS tracking, performance metrics, and a unique speed-based color heatmap for your routes.

Detailed documentation is available in the following guides:

- **[Feature Guide](FEATURES.md)**: Explore the core features like the GPS Dashboard, Live Map Heatmap, Ride Archiving, and customizable Speed Settings. Includes logic flowcharts and data models.
- **[CI/CD & Release Guide](CI_CD_GUIDE.md)**: Detailed explanation of the automated release pipeline, versioning logic, and GitHub Actions integration.
- **Patch Notes**: See the latest release updates and fixes documented below.

## 🚀 Key Features

- **Live Tracking**: Real-time stats (Distance, Time, Top Speed) on a high-visibility dashboard.
- **Speed Heatmap**: Path polyline color changes dynamically based on your speed.
- **Photo Logging**: Capture photos during your ride; they'll show up precisely where you took them on the map.
- **Archiving & Export**: Organize your rides and export them as JSON or GPX files.
- **Customizable**: Full control over speed thresholds and heatmap colors.

## 🛠️ Getting Started

1.  **Clone the repo**: `git clone https://github.com/omkarpradhan12/ride_tracker_1.git`
2.  **Install dependencies**: `flutter pub get`
3.  **Run the app**: `flutter run`
